## 👋 About me

I'm **Gaurang** — I build AI-powered applications with a focus on making them **trustworthy and reproducible**: grounded answers over real data, measurable evaluation, and pipelines that keep that data fresh.

- 🔭 Working on **grounded RAG / Text-to-SQL** assistants and **agentic workflows**
- 🧪 Obsessed with **evaluation**: if a hallucination can't be measured, it can't be reduced
- 🛠️ Comfortable across the stack — from scrapers and ETL to APIs and chat UIs
- 🌱 Always learning, always shipping
